# Time Tracker

A modern, dark-themed time tracking app with cloud sync, analytics, and goal setting. Built for mobile-first usage.

## Features

- **Timer**: Fullscreen timer with live updates and subsecond precision
- **Analytics**: Track time by category, daily trends, and top tasks
- **Goals**: Set daily, weekly, or monthly time goals
- **Cloud Sync**: Auto-sync across devices with Supabase
- **Mobile First**: Optimized for phone usage with responsive design
- **Dark Theme**: Artistic dark theme with gradient accents
- **Export**: Download task history as CSV

## Tech Stack

- React + Hooks
- Supabase (Auth + Database)
- Tailwind CSS
- LocalStorage for offline support
